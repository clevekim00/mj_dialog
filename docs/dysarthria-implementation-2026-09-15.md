# 마비말장애 연습 앱 개선 구현

2026-09-15 · [기존 검토서](dysarthria-app-review-2026-09-13.md)를 바탕으로 한 구현 결과.

## 사용 흐름

홈의 **자음 골라 연습하기 → 초성 또는 받침 → 자음 → 음절·단어·문장**에서 연습한다. 이번 세션의 녹음 목표를 3·5·10회 중 고르고, 예시를 듣거나 직접 녹음한다. 녹음은 먼저 기기에 저장하며, 같은 항목의 이전 녹음을 다시 들어볼 수 있다. 목표 횟수에 도달하면 완료 상태가 표시되고, 중간에 나가면 홈에서 이어할 수 있다.

## 콘텐츠와 서버 분석

한국어 내장 팩은 `2026.09.2`, 25개 목표·800항목이다. 잘못된 조사 결합을 만드는 템플릿을 제거했다. 문장 500개는 생활 원문 125개에 시간 문맥 네 가지를 적용한 것이며, 전문가 검수 완료 콘텐츠로 표시하지 않는다. 새 내장 팩보다 오래된 다운로드가 우선하던 문제도 수정했다.

기본 예시는 **TTS 합성 음성**으로 표시한다. `referenceAudioAsset`을 제공하면 해당 예시 녹음을 재생할 수 있으나 이번 작업에서 전문가 기준 음성을 제작하지는 않았다.

외부 분석은 녹음 후 별도로 요청한다. 전송 대상과 전송 항목을 보여주고 해당 녹음에 대한 동의를 받아야 전송한다. 클라이언트의 전체·개별 요청 시간 제한, 취소, 작업 삭제를 구현했다. 서버는 개발 시 loopback 전용이며 운영 시 HTTPS, 단기 서명 토큰, 작업 소유권, 결과 만료, 업로드 크기·시간·요청·동시 실행 제한을 적용한다.

검증되지 않은 CTC 점수 계산을 중단했다. MFA는 음소 정렬 정보를 제공하되 검증된 채점 방식이 없는 경우 점수를 비운다. 자음 결과는 `scoreValidated == true`인 경우에만 점수 표시·기준선 비교를 허용한다.

**운영 로그인과 토큰 발급 서버는 별도 연동이 필요하다.** 현재 저장소의 기본 앱은 자동으로 외부 분석 서비스에 로그인하지 않는다. 설정과 인증 연동은 [서버 README](../server/pronunciation_analysis/README.md)에 설명했다.

## 검증

| 확인 | 결과 |
|---|---|
| Flutter 전체 테스트 | 121개 통과 |
| Flutter 정적 분석 | 오류·경고 없음 |

| 실제 화면 재확인 | Mac 잠금으로 수행하지 못함. 320/390px·글자 200% 위젯 회귀 테스트 통과 |

회귀 테스트에는 인식 실패, 점수 없는 기록, 기존 점수 분리, 무발화 게임 이벤트, 녹음 시작 대기 중 중지, 저장 실패 재시도, 분석 취소·무응답, 최종 STT 지연, 구강 반복 유지·이어하기·늦은 일시정지, 프로필 로드, 큰 글씨와 고정 버튼을 포함한다.

## 남은 검증과 범위

- iOS 시뮬레이터 빌드는 컴파일·링크 이후 Gemma 모델 자산 복사에서 저장공간이 부족했다. `BUILD SUCCEEDED` 표시만으로 패키징 성공으로 판단하지 않았다. 이번에 만든 임시 iOS 빌드 파일만 정리했으며 원본 모델·기존 프로젝트 빌드는 유지했다.
- 실제 마비말장애 사용자·언어재활사와 함께 콘텐츠 및 연습 강도를 검토해야 한다. 이 구현으로 치료 효과나 자동 평가의 임상 정확도를 입증한 것은 아니다.
- iOS/Android 실제 기기에서 마이크·카메라·느린 말·긴 쉼·통화 중단·VoiceOver/TalkBack 사용성을 확인해야 한다. 위젯 테스트는 실기기 접근성 검사를 대체하지 않는다.
- 목표 시간은 추천 분량의 안내값이다. 일반 문장 연습을 강제로 종료하는 처방·시간제한은 추가하지 않았다.
- 로컬 저장의 앱 수준 암호화, OS 백업 정책, 전체 자료 보관·삭제 설정은 후속 제품 정책과 함께 다룬다.
- 이번 작업에서 외부 서버 배포, 로그인 시스템 구축, 임상 모델 학습, 전문가 음성 제작은 수행하지 않았다.
