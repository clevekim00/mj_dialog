## 1. 제품 결정

가이드는 사용자가 연습 중 필요한 순간에 열고, 자기 속도로 확인한 뒤 말하도록 한다. 파형은 음량·쉼의 흐름을 살펴보는 보조 표시이며 발음 정확도나 회복 점수가 아니다. 발성 게임은 동기 부여용 시제품으로 제공한다. **게임의 연속 검출 시간을 임상 MPT로 표시하지 않는다.**

## 2. 구현한 사용자 흐름

### 과제 안에서 안내 받기

`오늘 → 연습 시작 → 피로 확인 → 먼저 들어요 → 한 부분씩 확인해요 → 준비되면 말해요 → 녹음 → 자기 확인`

- 과제의 실제 문구에 연결된 안내를 제공한다. 예시 재생은 사용자가 누를 때만 시작하며 TTS임을 표시한다.
- `/`가 있으면 쉼 단위, 없으면 어절 단위로 나눈다. 각 부분을 눌러 따로 들을 수 있다. 이 구분은 음향 분석으로 찾은 경계가 아니다.
- 한국어 첫 음절의 초성을 확인할 수 있다. 모음 앞 무음 초성 ㅇ은 자음 발음 지시로 내보내지 않는다. 음절 끝소리나 연음 규칙을 자동 처방하는 기능은 아니다.
- ‘물을 달라고 부탁하기’를 추가했다. `물 → 물을 주세요 → 가족에게 부탁하기`를 한 계획으로 실행할 수 있다.
- 단계가 자동으로 넘어가지 않으며 언제든 안내를 접거나 다시 펼칠 수 있다. 다음 연습에서 안내를 접고 시작하는 선택을 로컬에 저장한다.
- 녹음 전 TTS·재생·연결된 시범을 중지한다. 사용자가 말하는 중 예시 음성을 재생하지 않는다.
- 기존 일반 문장 연습에도 `가이드·소리 흐름으로 연습` 진입을 추가했다. 기존 분석 엔진을 무리하게 교체하지 않고 같은 문구를 새 녹음 흐름으로 전달한다.

### 거울 보기

- 기본 꺼짐. 눌렀을 때만 카메라를 초기화한다.
- 미리보기만 제공하며 이 기능에는 영상 녹화·저장 호출이 없다.
- 권한 거부/미지원 기기는 안내 후 음성 연습을 계속할 수 있다.
- 앱이 비활성화되거나 화면이 사라지면 카메라를 해제한다. 다시 돌아와도 자동으로 켜지 않는다.
- 기존 입모양 녹화 기능은 별도 기능으로 유지한다.

### 영상 콘텐츠 적용 조건

`ReviewedSpeechMedia`에 정확한 발화 문구, 검수 식별자, 콘텐츠 버전, 음성 동기화 여부를 둔다. 문구와 검수 조건을 만족하는 자산만 시범 플레이어에 들어갈 수 있다. 자동재생·무한 반복은 하지 않으며, 실패하면 글·음성 안내를 계속 이용할 수 있다.

**현재 새 과제에 연결한 임상 검수 영상은 없다.** 기존 8개 구강·호흡 무음 영상은 원래 화면에 유지했다. 해당 영상을 ‘물을 주세요’ 같은 발화의 정확한 입모양이라고 재사용하지 않았다. 새 영상 생성, 혀 단면 해부 애니메이션, 전문가 검수 완료는 이번 구현으로 주장하지 않는다.

추가 제작 순서:

1. 물/생활 문장 1세트의 자연스러운 음성·입모양 동시 시범을 확보한다.
2. 검수자가 문구·입술 접촉·관찰 시점·음성 동기화를 확인한다.
3. 필요한 위치 그림만 추가하고, 보이지 않는 혀 동작을 외부 영상에서 추정하지 않는다.
4. 승인된 자산과 검수 정보로 `ReviewedSpeechMedia`를 연결한다.
5. 혼자 이해·시작·중단할 수 있는지 확인한 뒤 확대한다.

## 3. 파형 구현

화면 명칭은 `소리 흐름 보기`와 `소리 크기 흐름`이다. 정확히는 PCM의 약 64ms 구간별 peak envelope이며 전체 신호를 한눈에 보는 용도다. 음절 정오·정확한 발음·dB SPL로 표시하지 않는다.

- 기존 Voice Tool의 `VoiceSignalAnalyzer`를 재사용한다. 새 경로는 계산량을 줄이기 위해 스펙트럼을 계산하지 않는다.
- `PracticeCapture`가 하나의 16kHz/mono/PCM16 입력으로 녹음과 그래프를 만든다. 녹음 서비스 옆에 분석용 마이크를 추가로 켜지 않는다.
- 녹음 중에는 선택적으로 실시간 그래프를 보고, 녹음 후/기록 상세에서는 저장된 전체 흐름을 본다.
- 파형 크기는 고정 full scale 기준이다. 녹음마다 최대값을 100%로 올려 음량이 같아 보이게 하지 않는다.
- 같은 문구 녹음 비교와 듣기를 유지한다. 마이크·거리·배경 소음이 달라지면 직접 비교에 제약이 있다.
- 새 경로는 WAV 전체를 저장한다. 기존 Voice Tool의 ‘최근 10초’ 재생 버퍼를 긴 발성 저장에 사용하지 않는다. 기존 도구 자체의 저장 구조는 이번에 변경하지 않았다.
- 과제당 녹음은 제품 메모리 제한 120초, PCM 약 3.84MB로 제한한다. 도달 시 받은 구간을 저장하고 쉼 상태로 전환한다. 이 제한은 권장 훈련 시간이나 MPT 검사 한도가 아니다.
- 입력 정지/오류는 종료·저장을 시도한다. 입력이 들어오지 않는 상태도 watchdog으로 감지한다.
- 파일 쓰기 실패 시 메모리의 PCM을 보존해 재시도한다. 기록 저장 실패 시 같은 ID로 재저장한다. 앱 강제 종료/프로세스 종료 시 미저장 메모리 복구는 보장하지 않는다.
- WAV는 기존 앱 문서 디렉터리의 `voice_analysis/rehab_*.wav`에 저장한다. 삭제 시 앱 소유 이름·경로 및 남은 참조를 확인한다.

## 4. 발성 게임 시제품

진입: `훈련 → 편안하게 소리 내기 → 목소리로 천천히 날기`.

| 항목 | 이번 구현 |
|---|---|
| 시작 | 피로 확인 후 수동 시작, 잠깐 조용히 주변 소리 확인 |
| 조작 | 신뢰 가능한 높이가 검출되면 새가 천천히 전진 |
| 높낮이 | 처음 검출된 소리로 기준을 잡고 상대 변화만 작게·부드럽게 반영 |
| 난이도 | 넓은 통로, 충돌 판정·탈락·순위·강도 상승 없음 |
| 쉬기 | 높이를 읽기 어려우면 움직임 정지. 소리를 더 크게 내라고 강요하지 않음 |
| 길이 | 최대 20초의 한 차례, 언제든 중단. 자동 반복 없음 |
| 종료 | 앱 비활성화/입력 중단에도 녹음과 가능한 결과를 저장 |
| 기록 | 별도 ‘발성 놀이’ 분류, 전체 녹음, 파형, 가장 긴 연속 검출 구간의 추정값 |
| 제외 | MPT, 호흡 능력 진단, 치료 효과 점수, 정상/비정상 판정 |

내부 알고리즘 `flight-feedback-v1`:

- 처음 약 0.8초 신호의 중앙 dBFS를 주변 소리 기준으로 사용한다.
- 기존 분석기의 pitch confidence ≥0.55, pitch ≥60Hz 및 입력 레벨 조건을 사용한다. 이는 기기 입력을 구분하는 시제품 임계값이며 임상 판정 기준이 아니다.
- 기준 음높이는 검출된 첫 8개 프레임의 중앙값이다. 최대 ±4 반음의 변화를 화면 중앙 주변으로만 반영한다. 사용자가 그 범위를 달성해야 하는 목표는 아니다.
- 검출되지 않은 프레임, clipping, 표본 시각 공백이 나오면 연속 구간을 끊는다. 여러 번 소리 낸 총합을 한 호흡 길이라고 합치지 않는다.
- 신호 검출은 사람/모음/호흡을 식별하지 못한다. 외부 음성·지속 소음은 잘못 검출할 수 있고, 약하거나 불규칙한 발성은 짧게 추정될 수 있다. 무검출은 ‘발성 능력 0’이 아니다.

## 5. MPT에 대한 결론과 별도 설계

기술적으로 발성 시작/끝을 추정할 수 있다. 하지만 높낮이를 바꾸고 여러 번 숨 쉬며 조작하는 게임 결과는 동일 조건의 MPT가 아니다. MPT에는 발성 방식·호흡·음높이·강도·측정 절차가 영향을 준다. 기존 분석기의 voiced frame 시간 합계도 연속된 한 호흡의 최대 발성 시간과 다르다.

후속 측정 모드는 게임과 분리해 설계한다:

1. 전문가가 적용 대상을 확인하고 모음·자세·호흡·편안한 음높이/크기·시행/휴식 절차를 정한다. 화면에는 움직이는 장애물이나 음높이 목표를 주지 않는다.
2. 단일 시행의 전체 녹음과 표본 기반 시각을 보존한다. 녹음 버튼 누른 시간부터 재는 타이머는 발성 시간이 아니다.
3. 자동 시작/끝 후보와 품질 경고를 표시하고, 녹음을 들으며 구간을 수동 수정할 수 있게 한다.
4. 기침·중간 들숨·지속 소음·잘림·검출 불확실성을 구분한다. 음높이를 못 찾았다는 이유만으로 무발성 처리하지 않는다.
5. 반복 시행은 독립 기록으로 남기며 검토된 유효 시행만 프로토콜에 맞게 요약한다. 중단하거나 앱 시간 한도에 도달하면 ‘최대치 확인 안 됨’으로 남긴다.
6. 같은 녹음을 전문가가 표시한 구간과 대조해 오차·실패율을 검증한 뒤 MPT 추정 기능으로 공개한다. 임의의 정상값이나 회복 점수는 제시하지 않는다.

**초기 구현 시점에는 MPT 검사 모드를 구현/검증하지 않았다. 이후 추가한 관찰자 타이머 방식은 아래 후속 변경을 참고한다.** 발성 게임과 신호 추정 기초를 구현하고, 임상 측정을 혼동하지 않도록 데이터/UI를 분리했다.

## 6. 코드와 호환성

- `lib/features/rehab/guide/`: 단계 안내, 검수 영상 계약, 미리보기 전용 거울.
- `lib/features/rehab/audio/`: 단일 PCM 캡처, 전체 WAV 저장, 파형 표시.
- `lib/features/rehab/game/`: 발성 피드백 알고리즘과 쉬운 비행 화면.
- `RehabTake`: 선택적 waveform/durationMs 추가. 과거 JSON은 빈 파형으로 읽는다.
- `RehabSession`: 선택적 feedback 추가. 게임 원본 참조는 기존 신규 세션 저장소를 사용하되 통합 조회에서 별도 종류로 표시한다.
- ASR 점수/난이도 결정과 연결하지 않는다. 네 개 상위 메뉴는 유지한다.

## 7. 검증 및 출시 전 확인

자동 검증: 전체 PCM 보존(12.8초 사례), 파일 실패 후 재저장, 권한 거부, 분할 PCM 합치기, 연속 구간 분리, 중복 프레임 제외, clipping/무검출, 입력 공백, 기준 높이와 완만한 이동, 수동 단계 진행, 안내 접기 유지, 200% 글자 크기, 백그라운드 게임 종료·저장, 기존 세션 호환.

macOS 빌드/화면 확인 결과와 최종 테스트 수는 아래 실행 결과에 기록한다. 실환자 음성으로 정확도 검증, iOS/Android 마이크·카메라 동시 사용, 실제 VoiceOver/TalkBack, 임상 영상 검수는 별도 확인 항목이다. 앱 마이크 권한을 새로 부여하거나 사용자의 음성을 임의로 수집하지 않고 UI와 합성 신호로 검증한다.

## 8. 근거와 제품 판단의 구분

- [ASHA Dysarthria in Adults](https://www.asha.org/Practice-Portal/Clinical-Topics/Dysarthria-in-Adults/): 개인별 목표와 말하기 체계에 따른 접근, 시각적 단서/피드백을 참고했다. 본 게임의 치료 효과를 뒷받침하는 자료라는 뜻은 아니다.
- [W3C 단계별 명확한 안내](https://www.w3.org/WAI/WCAG2/supplemental/patterns/o4p07-step-instructions/): 수행 위치 가까이에 짧은 단계·예시를 제공하는 UI 원칙을 참고했다.
- [ASHA 음성 기기 평가 프로토콜](https://pubs.asha.org/doi/10.1044/2018_AJSLP-17-0009): 지속 모음에서 습관적 음높이·크기와 일관된 조건의 중요성을 참고했다. 이 문헌의 짧은 음향 표본 과제를 MPT 검사와 동일시하지 않는다.
- [Maximum Phonation Time in Healthy Older Adults](https://pmc.ncbi.nlm.nih.gov/articles/3128209/): MPT 시행과 반복/휴식 조건을 다루는 연구. 건강한 노인의 연구 절차/결과를 마비말장애 사용자에게 그대로 처방하지 않는다.

0.8초 보정·20초 게임·120초 녹음 제한·화면 이동 폭은 이번 시제품의 공학적 선택이다. 임상 권장량으로 사용하지 않는다.

## 9. 실행 결과

- `flutter analyze --no-pub`: 경고·오류 없음.
- 전체 회귀 테스트: 140개 통과.
- 이후 카메라 인계/게임 기록 분리 관련 6개, 안내의 즉시 멈추기/기존 저장·재개 관련 8개 테스트 통과(중복 실행 포함).
- macOS debug 빌드 성공. 실제 앱에서 새 훈련 메뉴와 발성 게임 준비 화면의 레이아웃·피로 확인·비활성 시작 버튼을 확인했다.
- 실사용자의 마이크·카메라 권한을 새로 부여하거나 발화를 수집하지 않았다. 음성 동작은 합성 PCM과 테스트 입력으로 검증했다.

## 10. 추가 변경: 자음·단어 음파 표시

- 자음 골라 말하기, 단어 말하기, 일반 말하기 화면에 `음파 보기`를 추가했다. 기본 켜짐이며 사용자가 숨길 수 있다. 오늘 연습의 `소리 흐름 보기`도 기본 켜짐으로 변경했다.
- 공통 파형의 실제 그림 높이를 88에서 352 logical pixel로 확대했다(4배). 작은 화면에서는 기존 스크롤을 사용한다. 입력값을 4배 증폭하거나 음량 척도를 바꾸지는 않는다.
- 기존 자음·단어 녹음은 파일 형식을 유지한다. 동일 녹음기의 음량 미터를 약 100ms마다 읽어 소리 크기 흐름을 표시한다. iOS는 기존 AVAudioRecorder의 metering을 활성화하고, 다른 지원 플랫폼은 record 플러그인의 amplitude를 읽는다. 추가 녹음기나 마이크 스트림은 열지 않는다.
- 이 음파는 원본 PCM의 진동 모양이 아닌 음량 추이이다. 오늘 연습의 PCM peak envelope와 추출 방식이 달라 절대값 직접 비교용으로 쓰지 않는다.
- 최근 파형은 녹음이 끝난 뒤에도 현재 앱 세션에서 볼 수 있고 다음 녹음 시작 시 초기화된다. 자음·단어의 과거 녹음에 파형을 영구 저장하거나 재생 시 파형을 복원하는 변경은 포함하지 않는다.
- 음량 조회 실패는 녹음을 중단시키지 않는다. 녹음 종료·서비스 해제 시 주기 조회를 중단하고 늦게 도착한 조회 결과를 무시한다.

검증: 전체 143개 테스트 통과, 테스트 의존 정리 후 음파 관련 2개 재통과. macOS debug 빌드 성공, iOS Swift 구문 검사 통과. 실제 iOS/Android 마이크 음량 및 기기별 표시 검증은 별도 확인이 필요하다.

## 11. 후속 변경: 관찰자 타이머 MPT

[별도 MPT 모드](../mpt-measurement.md)를 추가했다. 사람이 시작·종료를 누르는 타이머로 한 호흡의 유효 시도 3회와 최장 시간, 녹음·파형·제외 사유를 저장한다. 자동 음높이 검출이나 게임 기록은 MPT 계산에 사용하지 않는다. 시행 흐름을 구현한 것이며 임상 검증은 별도로 필요하다.
