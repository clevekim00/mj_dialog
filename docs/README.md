## 두 언어 문서 관리

문서를 수정할 때는 국문·영문을 함께 갱신합니다. 명령어·경로·API 식별자·발음 예시는 보존하고 설명과 접근성 문구를 번역합니다. 제작 도구에 입력하는 영문 프롬프트는 국문 제작 명세에서도 실행용 예제로 유지합니다.

자동 생성된 의존성 목록, 빌드 설정, 앱 시작용 HTML, 코드·자산 및 임시 그래프 추출 자료는 설명 문서가 아니므로 이 목록에서 제외합니다.

`python3 tools/docs/check_bilingual_docs.py`로 번역본 누락, 언어 이동, 목록 포함 여부와 로컬 링크를 확인합니다. 문서 구조 검사이며 번역 품질이나 임상 타당성 검증은 아닙니다.
