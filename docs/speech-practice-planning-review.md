# 말하기 연습 앱 기획 검토

작성일: 2026-05-08

## 1. 기획 방향

이 앱은 말하기가 불편한 사용자가 집에서도 짧고 꾸준하게 말하기 연습을 할 수 있도록 돕는 보조 도구다. 핵심은 AI 점수 자체보다 안전한 반복 연습, 개인 목표 설정, 변화 기록, 보호자와 함께 보기 쉬운 경과 확인에 있다.

제품의 중심은 다음 흐름에 둔다.

```text
안전한 자가 연습
→ 사용자 맞춤 반복 훈련
→ 말 명료도와 의사소통 참여 개선
→ 보호자/전문가와 공유 가능한 기록
→ 전문적인 평가를 대체하지 않는 연습 도구
```

## 2. 현재 앱이 갖춘 기반

현재 앱에는 말하기 연습 도구로 발전시킬 수 있는 기본 요소가 이미 있다.

```text
음성 기반 대화
→ ChatScreen, ChatController, SttService, TtsService

소리 내어 읽기 연습
→ PracticeScreen, PracticeNotifier, PracticeSentenceService

녹음 및 재생
→ AudioRecorderService, AudioPlayerService

연습 기록
→ PracticeHistoryService, PracticeHistoryScreen

성과 확인
→ DashboardScreen

권한 안내
→ PermissionScreen, PermissionService
```

강점은 다음과 같다.

- 텍스트 입력보다 음성 중심 UI에 가까워 실제 발화 연습과 잘 맞는다.
- 문장 읽기와 자유 발화가 둘 다 있어 정형 연습과 일상 말하기 연습을 함께 다룰 수 있다.
- 녹음 재생 기능이 있어 자기 발화를 다시 듣는 훈련으로 확장하기 쉽다.
- 연습 기록과 대시보드가 있어 반복 훈련을 습관화할 기반이 있다.

## 3. 이번 반영 사항

2026-05-08 기준으로 아래 개선사항을 코드에 반영했다.


## 4. 추가로 필요한 기능

### 4.1 사용자 상태 기반 초기 설정

현재 온보딩은 안전 고지와 기본 목표 설정까지 포함한다. 다음 단계에서는 사용자의 말하기 어려움 유형과 일상 목표를 더 세밀하게 받을 필요가 있다.

필요 기능:

- 주된 어려움 선택: 작게 말함, 말이 빠르거나 느림, 발음이 흐림, 숨이 짧음, 억양이 단조로움
- 보호자 메모 필드
- 사용자가 가장 자주 말하고 싶은 문장 등록
- 오늘 컨디션과 피로도 기록

### 4.2 구조화된 연습 세션

현재는 녹음하고 피드백을 받는 단일 루프에 가깝다. 말하기 연습 앱으로는 짧은 세션 단위가 더 적합하다.

권장 세션 구조:

```text
준비
→ 오늘 컨디션/피로도 체크

워밍업
→ 짧은 모음 발성 또는 쉬운 문장

핵심 연습
→ 개인 목표 문장 3-5개
→ 각 문장 3회 반복

일상 말하기
→ 실제 생활 상황 문장 1개

마무리
→ 오늘 변화, 어려웠던 점, 다음 과제 표시
```

### 4.3 점수 체계 개선

단일 점수는 이해하기 쉽지만, 사용자와 보호자에게는 어떤 부분이 좋아졌는지 더 구체적인 설명이 필요하다.

추천 지표:

```text
말 명료도
→ 목표 문장과 인식 텍스트의 유사도

말 속도
→ 녹음 길이와 문장 길이 기반

음량 안정성
→ 녹음 크기 변화 기반

호흡 지속
→ 중간 끊김과 한 번에 말한 길이 기반

억양/리듬
→ 현재는 AI 피드백 텍스트로 시작하고 이후 음성 특징 분석 검토
```

주의할 점:

- 전문적인 평가 점수처럼 표현하지 않는다.
- 사용자 간 비교보다 자기 이전 기록 대비 변화 중심으로 보여준다.
- 마이크 문제, 무음, 주변 소음과 실제 발화 어려움을 구분한다.

### 4.4 기능적 문장과 빠른 표현

현재 기능적 문장을 일부 추가했다. 다음 단계에서는 사용자가 자주 쓰는 문장을 빠르게 꺼내 연습하거나 전달할 수 있어야 한다.

추가할 문장 카테고리:

- 병원: "통증이 있어요", "물을 마시고 싶어요", "어지러워요"
- 집: "도와주세요", "화장실에 가고 싶어요", "천천히 말할게요"
- 가족: "오늘 기분이 좋아요", "조금 쉬고 싶어요"
- 전화: "다시 말씀해 주세요", "천천히 말하겠습니다"
- 감정: "답답해요", "고마워요", "괜찮아요"

추가 UI:

- 자주 쓰는 문장 즐겨찾기
- 큰 버튼 문장판
- 첫 글자 힌트
- 보호자가 대신 문장을 골라주는 화면

### 4.5 보호자/전문가 공유

현재 공유 기능은 녹음 파일 공유에 가깝다. 보호자나 전문가에게는 요약 리포트가 더 유용하다.

리포트에 포함할 항목:

- 기간별 연습 횟수
- 최근 7일 연습 지속성
- 평균 점수보다 목표별 변화
- 자주 어려웠던 문장
- 피로도 변화
- 녹음 샘플 링크 또는 파일
- 사용자 메모와 보호자 메모

### 4.6 접근성 강화

말하기가 불편한 사용자는 손 조작, 시야, 주의 집중, 피로도 측면에서도 어려움을 겪을 수 있다.

필요 개선:

- 큰 버튼 모드
- 한 손 조작 모드
- 글자 크게 보기
- 긴 설명 줄이기
- 색만으로 점수 구분하지 않기
- 음성 안내
- 보호자가 대신 조작하기 쉬운 화면

## 5. 추천 개발 순서

1. 온보딩 문구와 안전 안내를 더 간결하게 다듬기
2. 5분/10분 연습 세션 템플릿 추가
3. 문장 반복 횟수와 휴식 타이머 추가
4. 점수를 명료도, 속도, 음량, 호흡 등 하위 지표로 분리
5. 보호자 공유 리포트 생성
6. 자주 쓰는 문장판과 즐겨찾기 추가

## 6. 결론

현재 앱은 음성 입력, 읽기 연습, 녹음 재생, 기록, 대시보드라는 좋은 뼈대를 갖고 있다. 앞으로의 방향은 "AI가 발음을 채점하는 앱"보다 "사용자가 매일 부담 없이 연습하고, 보호자와 함께 변화를 확인하는 앱"에 맞추는 것이 좋다.

다음 제품 목표는 아래처럼 정리할 수 있다.

```text
사용자가 매일 짧게 연습하고,
보호자가 변화를 이해하며,
앱은 안전한 연습 동반자로 남는다.
```
