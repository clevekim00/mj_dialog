## 제공 기능과 범위

**훈련 → 편안하게 소리 내기 → 최대발성시간 (MPT)**. 기본은 발성 자동 감지이며, 준비를 한 번 누른 뒤 발성 시작·종료 버튼을 누르지 않아도 된다. 발성 놀이와 기록을 분리한다. 자동 감지를 끄면 기존 관찰자 타이머를 사용한다. 한 세트 안에서는 측정 방식을 바꾸지 않는다.

자동 측정은 음향 신호에서 발성 구간을 추정한다. “아”라는 모음인지, 한 번의 호흡인지, 기침인지 자동으로 검증하지 않는다. 약하거나 불규칙한 목소리·주변 소음에 오차가 생길 수 있다. 임상 검증된 검사나 진단 도구가 아니며 정상/비정상 판정을 제공하지 않는다.

## 사용 방법

1. 조용한 곳에서 같은 기기·마이크 거리·환경을 유지한다. 피로도를 고르고 충분히 쉬었음을 확인한다.
2. **녹음 준비**를 한 번 누른다. 약 1.5초 동안 조용히 기다려 주변 소리를 확인한다.
3. **준비됐어요** 안내 후 숨을 충분히 들이마시고 편안한 높이·크기로 “아~”를 한 번의 날숨 동안 이어 낸다. 힘주거나 억지로 버티지 않는다.
4. 소리가 감지되면 하단의 큰 타이머가 자동으로 시작한다. 소리가 끝나면 자동 종료된다. 시작·종료 확인에 사용한 대기 시간은 측정 구간에 더하지 않는다.
5. **녹음 듣기**로 확인한다. 한 호흡, 방해 소리 없음, 올바른 시작·끝을 확인한 시도만 **유효 시도로 저장**한다. 중간 호흡, 잘못 감지된 구간, 기침 등은 제외한다. 짧은 끊김 감지 안내가 있으면 특히 확인한다.
6. 충분히 쉰 뒤 준비·발성·확인을 반복한다. 확인된 유효 시도 3회 중 최장 시간이 결과이며 합계·평균은 쓰지 않는다.
7. **기록 → MPT 측정**에서 자동 추정/관찰자 방식, 시간, 포함·제외 여부와 녹음을 본다. 미완료 세트는 이어서 측정할 수 없으며 새 세트를 시작한다.

자동 감지가 어렵다면 새 세트에서 **발성 자동 감지**를 끈다. 보호자·검사자가 실제 소리 시작·끝에 타이머 버튼을 누르는 기존 방식을 사용한다. 통증·어지러움·숨참이 있으면 하단 중단 버튼을 누른다. 자동화는 발성 중 버튼 조작을 줄이는 기능이며 준비와 녹음 확인까지 없애는 기능은 아니다.

## 측정과 실패 처리

- 단일 PCM 입력(16 kHz, 16-bit mono)을 녹음·분석에 함께 사용한다. 약 64 ms 단위 프레임의 실제 오디오 시각으로 구간을 계산한다. 0.1초 표시는 측정 정확도를 보장하지 않는다.
- 주변 소리 확인 1536 ms, 배경 음량 대비 10 dB 높은 시작 기준(-55~-20 dBFS 제한), 유성 신호 192 ms 지속으로 시작을 확인한다. 확인된 첫 프레임으로 시작점을 되돌린다. 이 수치는 제품의 초기 구현 값이며 임상 표준값이 아니다.
- 종료는 마지막 발성 뒤 무음 640 ms로 확인한다. 결과는 마지막 발성 프레임까지이며 뒤의 무음은 제외한다. 짧은 끊김은 이어진 구간에 포함되므로 녹음 검토가 필요하고, 감지된 끊김은 기록에 남긴다.
- 주변 소리 확인 중 목소리나 큰 소음이 있거나, 준비 후 20초 동안 발성을 찾지 못하면 제외 시도로 종료한다. 큰 소리를 억지로 내지 말고 환경을 확인하거나 수동 방식을 사용한다.
- 앱 이탈·입력 끊김·오류·120초 녹음 한도는 제외한다. 120초는 메모리 한도이지 MPT의 임상 제한 시간이 아니다.
- 모든 시도는 먼저 미확인 상태로 저장한다. 녹음 검토 전에는 최종 결과에 포함하지 않는다. 파일·기록 저장 실패 시 같은 시도와 종료 시각으로 재시도하며 새 측정을 막는다.

## 저장 구조와 검증

`RehabSession.feedback.kind = mpt`. 자동 방식은 `version = mpt-auto-reviewed-3-trials-v1`, `timingMethod = automatic-acoustic`, `detectorVersion = adaptive-voice-v1`이며 감지 설정을 함께 저장한다. 수동 방식은 기존 `mpt-observer-3-trials-v1` / `observer-stopwatch`를 유지한다. 시도별 시간·녹음 구간·방식·끊김 감지·유효 여부·제외 사유를 보존한다. 구형 기록의 방식은 관찰자 타이머로 해석한다. 3회 확인 전 `maximumMs`는 null이다. MPT는 일반 연습 재개·발음 비교·일일 연습량에서 분리한다.

자동 시작·끝, 끝 무음 제외, 짧은 소리 거부, 끊김, 무음 대기, 소음, 기존 수동 측정, 저장 실패·재시도와 권한 오류를 테스트한다. 실제 약한 발성·소음 환경에서 전문가의 수동 계측과 비교하는 임상/기기 검증은 별도로 필요하다.

## 근거

[ASHA 성인 마비말장애 평가](https://www.asha.org/practice-portal/clinical-topics/dysarthria-in-adults/)는 지속 모음 발성을 평가 항목으로 설명한다. [PhenX 성인 MPT 프로토콜](https://s3.amazonaws.com/phenx-portal/public/phenx-content/consensus/speech_hearing/14_Voice_Impairments_MPT.pdf)의 한 호흡 모음 발성과 3회 최장 시간 원칙을 참고한다. 자동 검출 기준·대기 시간·UI는 이 앱의 구현 결정이며 이 자료가 본 자동 알고리즘을 검증한 것은 아니다.
