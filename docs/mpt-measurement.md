# 최대발성시간(MPT) 측정

[한국어](mpt-measurement.md) | [English](mpt-measurement.en.md) | [전체 문서](README.md)

## 제공 기능과 범위

연습 → 편안하게 소리 내기 → **최대발성시간 (MPT)**에서 실행한다. 발성 게임과 별도 화면·기록 분류를 사용한다. 보호자나 검사자가 실제 발성의 시작과 끝에 버튼을 눌러 시간을 재는 **관찰자 타이머 방식**이다. 자동 음성 검출로 약하거나 불규칙한 음성을 잘못 자르는 문제를 피하며, 사람이 한 호흡과 측정 구간을 확인한다.

MPT 시행 절차를 기록하는 기능이며 임상적으로 검증된 자동 검사나 진단 도구는 아니다. 전문 평가의 대체, 정상/비정상 판정, 회복 점수, 성별 정상 범위는 제공하지 않는다. 임상 해석은 전문가에게 맡긴다.

## 사용 방법

1. 조용한 곳에 편안히 앉는다. 같은 기기·마이크 거리·환경을 유지한다. 보호자·검사자가 안내와 타이머를 맡는다.
2. 피로도를 선택하고 충분히 쉬었으며 도와줄 사람이 준비됐음을 확인한다. 힘들면 측정을 미룬다.
3. **녹음 준비**를 누른다. 준비 시간이 MPT에 포함되는 것은 아니다.
4. 숨을 충분히 들이마신 뒤 평소의 편안한 높이와 크기로 “아~”를 한 번의 날숨 동안 가능한 만큼 이어 낸다. 억지로 힘주지 않는다.
5. 도와주는 사람이 실제 소리가 시작될 때 **소리 시작 · 타이머 시작**, 끝날 때 **소리 끝 · 타이머 종료**를 누른다. 시작을 누르고 기다린 시간이나 숨을 들이마시는 시간을 포함하지 않는다.
6. 녹음과 파형을 확인한다. 한 호흡, 기침·방해 소리 없음, 적절한 시작·종료를 확인한 시도만 **유효 시도로 저장**한다. 중간 호흡, 잘못 누른 타이머, 부정확한 녹음은 제외한다.
7. 충분히 쉰 뒤 같은 방식으로 유효 시도 3회를 모은다. **세 시간 중 최장 시간**이 최종 MPT다. 합계나 평균은 사용하지 않는다.
8. 기록 → **MPT 측정**에서 시도별 시간, 포함/제외 여부, 최종 결과와 녹음을 확인한다. 미확인 상태로 나가도 기록은 남지만 유효 시도에 포함되지 않는다. 미완료 세트는 이어서 측정하지 않으며 필요하면 새 세트를 시작한다.

통증, 어지러움, 숨참이 있으면 즉시 중단한다. 오래 버티는 경쟁이나 매일 반복하는 목표로 사용하지 않는다. 개인별 시행 여부와 분량은 전문가와 상의한다.

## 측정과 실패 처리

- 단조 증가 `Stopwatch`로 버튼 사이 시간을 재며 0.1초 단위로 표시한다. 표시는 측정 정확도를 보장하지 않는다. 관찰자의 반응 시간과 버튼 조작 오차가 있다.
- 녹음은 기존 단일 PCM 입력(16 kHz, 16-bit mono)을 사용한다. 준비 구간을 포함한 전체 녹음과 파형, 버튼 시점의 녹음 위치를 보존한다. 파형은 음량 표시이며 발성 정확도 판정이 아니다.
- 자동 VAD, pitch 검출, 게임의 누적 검출 시간을 MPT 계산에 사용하지 않는다. 사람의 확인은 음성 내용·호흡 여부를 자동 검증하지 않는다.
- 앱이 배경으로 이동하거나 마이크가 끊기면 해당 시도를 제외한다. 시작·종료 사이 녹음이 없거나 시간이 0인 경우에도 채택할 수 없다.
- 기존 녹음의 120초 제한에 도달하면 **제외 시도**로 저장한다. 120초를 최대 발성 능력이나 완성된 MPT 결과로 표시하지 않는다. 이 한도는 메모리 제한이며 임상 프로토콜의 제한 시간이 아니다.
- 각 시도는 먼저 미확인 상태로 저장하고 사용자 확인 후 갱신한다. 3회가 채택되기 전 `maximumMs`는 null이다. 유효하지 않은 시도는 이력을 남기고 다시 시도할 수 있다.
- 파일 또는 기록 저장 실패 시 새 측정을 막고 재시도를 제공한다. 같은 시도 ID를 사용하며 최초 종료 시각을 유지한다. 저장 실패 안내가 남아 있을 때는 앱을 닫지 말고 재시도한다. 강제 종료 시 메모리에 남은 미저장 데이터의 복구는 보장하지 않는다.

## 저장 구조와 검증

기존 `RehabSession` 저장소에 `feedback.kind = mpt`, `version = mpt-observer-3-trials-v1`, `timingMethod = observer-stopwatch`로 저장한다. 각 시도는 ID, 타이머 지속 시간, 녹음 시작/종료 위치, 유효 여부, 제외 사유를 가진다. `maximumMs`는 정확히 3개의 확인된 유효 시도에서만 계산한다. 미완료 상태는 `partial`, 완료는 `completed`다. 일반 문장 연습의 재개·비교 대상으로 연결하지 않는다. 녹음 재생·공유·삭제는 기존 기록 기능을 사용한다. MPT 측정은 오늘의 연습 집계에서 제외한다.

`test/mpt_test.dart`는 3회 최댓값·미완료·중단·입력 실패·저장 재시도·마이크 권한 오류와 기록 분리를 확인한다. 이 테스트는 임상 검증이 아니다. 출시 전 실제 기기의 녹음·오디오 지연·백그라운드 중단과 전문가 수동 시간 계측 대비 오차를 확인해야 한다.

## 근거

[PhenX 성인 MPT 프로토콜](https://s3.amazonaws.com/phenx-portal/public/phenx-content/consensus/speech_hearing/14_Voice_Impairments_MPT.pdf)은 편안한 높이·크기에서 한 호흡의 모음 /아/를 지속하고, 세 시도 중 가장 긴 시간을 채택하는 절차를 제시한다. 본 구현은 이 시행 원칙을 참고한다. 녹음 검토, 오류 처리, 120초 메모리 한도와 앱 UI는 제품 구현 결정이다. 원문의 정상 범위를 앱의 판정 기준으로 사용하지 않는다.
