## 기본 메뉴

**오늘 → 훈련 → 게임 → 기록 → 설정**. 좁은 화면은 하단 메뉴, 넓은 화면은 왼쪽 메뉴에서 같은 순서를 제공합니다.

| 메뉴 | 제공 내용 |
|---|---|
| 오늘 | 오늘의 연습 계획, 진행 중 연습 이어서 하기 |
| 훈련 | 구강 훈련, 자음 골라 말하기, 짧은·긴 문장, 생활 상황, 말 속도·쉼, 편안한 발성, MPT |
| 게임 | 단어 말하기 게임, 한 음절 모험 달리기, 목소리로 천천히 날기 |
| 기록 | 훈련·게임·MPT 기록을 모아 보고 종류별로 선택 |
| 설정 | 목표, 글자 크기, 언어, 녹음·콘텐츠 관리 |

## 게임 이용 방법

게임 화면의 안내는 **“말하기를 놀이로 연습해요.”**입니다. 세 가지 말하기 놀이를 제공하며, 새로운 치료 효과나 점수를 의미하지 않습니다.

- **게임 → 단어 말하기 게임:** 이전 화면의 연습 모드를 정리한 뒤 단어 모드로 엽니다. 시간 제한 없는 방식이 기본입니다. 낙하 모드는 게임 안에서 선택할 수 있습니다. 기존 녹음, 파형, 복습과 일시정지 동작은 유지합니다.
- **게임 → 목소리로 천천히 날기:** 편안한 “아~” 소리에 따라 새가 움직입니다. 충돌·탈락 없이 쉬운 방식이며 한 차례는 최대 20초입니다. 중간에 쉬어도 됩니다. 검출 시간은 MPT 결과가 아닙니다.

이전의 `훈련 → 또렷하게 말하기 → 단어 말하기`와 `훈련 → 편안하게 소리 내기 → 목소리로 천천히 날기` 진입점은 게임 메뉴로 이동했습니다. 훈련 화면에서는 중복 게임 카드를 제거했습니다.

## 훈련에 남는 기능

- **훈련 → 구강 훈련:** 구강·호흡 훈련 허브를 엽니다. 별도 최상위 메뉴는 아닙니다.
- **훈련 → 편안하게 소리 내기 → 최대발성시간(MPT):** 자동 발성 감지(수동 타이머 선택 가능)로 한 호흡 발성 3회를 기록하고 녹음을 확인합니다. 게임 점수와 합치지 않습니다. [측정 방법과 한계](mpt-measurement.md)를 확인하세요.
- **훈련 → 편안하게 소리 내기 → 문장 끝까지 말하기:** 예시 문장을 읽으며 소리 흐름을 확인합니다.
- 오늘의 연습 안에 포함된 단어 과제는 그대로 유지합니다. 이동한 것은 별도 단어 게임의 진입점입니다.

## 기록과 호환성

기록의 **게임** 필터에 단어 게임과 발성 놀이를 함께 표시합니다. 두 게임은 제목과 녹음 내용으로 구분합니다. 기존 단어 게임의 `mode = wordGame`과 발성 놀이의 `feedback.kind = voiceFlight` 저장 형식을 유지하므로 이전 기록을 다시 작성하거나 삭제하지 않습니다. 단어 게임의 녹음 관리 연결도 유지합니다. MPT는 별도 **MPT 측정** 분류입니다.

## 구현과 확인

- `GameMenuScreen`: 세 게임 선택 화면, 중복 진입 방지, 실패 안내.
- `AdaptiveAppShell`: 5개 메뉴와 화면 너비 변경 시 선택 메뉴 유지.
- `ExerciseMenuScreen`: 기존 게임 진입점 제거, MPT·구강 훈련 유지.
- `RehabRecordIndex`: 기존 단어 게임 기록을 게임 필터에 표시.
- `test/game_menu_test.dart`: 진입 모드 초기화, 시간 제한 기본값, 양 언어·작은 화면, 발성 게임 진입, 기존 기록 보존.
- 기존 앱 탐색·단어 게임·MPT·기록 테스트로 회귀를 확인합니다. 이 검사는 소프트웨어 동작 검사이며 임상 검증이 아닙니다.

## 한 음절 모험 달리기

**게임 → 한 음절 모험 달리기**. 오른쪽을 향해 자동으로 달리며 자음 19개 중 하나를 고른다. 선택한 자음에 **ㅏ를 붙이면 점프**, **ㅓ를 붙이면 숙이기**다. ㄱ은 가/거, ㅁ은 마/머, ㅇ은 아/어다. 언어 설정이 영어여도 음성 조작은 한국어다.

치즈(노란 코숏 수컷)와 모찌(흰 코숏 암컷)를 선택한다. 장애물이 멀리 있어도 점프·숙이기가 가능하다. 동작은 1.5초이며 동작 중 중복 입력은 무시한다. 장애물이 접근 구간의 75% 이상 왔을 때 알맞은 동작을 하면 통과한다.

햇살 초원 12개, 구름 언덕 16개, 별빛 산책 20개의 3개 스테이지다. 접근 시간은 각각 6·5.5·5초다. 한 스테이지는 약 1~3분이며 편안 모드에서는 더 천천히 해도 된다. 완료 후 다음 스테이지를 직접 시작한다.

기본 **편안 모드**는 장애물 앞에서 계속 기다리며 건너뛰기가 가능하다. **도전 모드**는 도착 후 3초 안에 피하지 못하면 충돌하여 멈춘다. 스테이지마다 첫 시도와 재시도 2회가 있다. 재시도는 해당 스테이지 처음부터이며 동작 수가 초기화된다. 기회를 모두 쓰면 새 게임을 시작하거나 편안 모드로 바꾼다. 음성 인식 지연도 도전 결과에 영향을 줄 수 있으므로 버튼을 함께 사용할 수 있다.

하단 버튼·↑/스페이스·↓로도 조작한다. 잠시 쉬거나 앱을 벗어나면 진행이 멈춘다. 캐릭터 변경은 진행을 유지하고, 자음·모드 변경은 새 게임을 시작한다. 플레이 중 선택 메뉴는 숨겨지며 쉬는 동안 다시 나타난다. 진행과 선택은 앱 종료 후 저장되지 않는다.

OS 한국어 음성 인식의 중간 결과를 사용한다. 현재 자음의 한 음절 전체가 맞을 때만 한 번 동작하며 긴 단어 안의 일부 글자로 동작하지 않는다. iOS에는 두 음절을 인식 힌트로 전달한다. 음성 인식 창을 짧게 갱신하며 자유 동작 후에도 다시 듣는다. 편안 모드는 네트워크 지연을 기다린다. 인식이 어렵다면 버튼을 사용한다. OS에 따라 네트워크·음성 인식 권한이 필요하다.

음성 동작·버튼 동작·건너뜀은 구분한다. 이 버전은 라운드 요약만 표시하며 기록 메뉴에는 저장하지 않는다. 앱은 녹음 파일을 저장하지 않는다. 인식 성공은 발음 점수나 임상 평가가 아니며 MPT를 측정하지 않는다.

## 기존 비행 게임 개선 방향 (아직 적용하지 않은 제안)

현재 게임은 소리에 따른 높이 변화와 시간 표시가 중심이어서 목표·선택·보상이 약하다. 다음 개선은 ① 짧은 구간의 별 모으기 ② 도착 지점과 구간별 배경 변화 ③ 발성 사이 쉬는 구간 ④ 편안한 발성 범위로 맞춘 넓은 통과 구간이다. 크게 소리 내기나 숨을 오래 참아야 이기는 규칙은 넣지 않는다. 게임의 발성 시간은 놀이 지표로 유지하고, 정식 MPT 3회 측정과 분리한다.

자음은 **자음 선택** 버튼의 19개 큰 선택 버튼으로 바꾼다. 플레이 중 선택창을 열면 일시정지하며 다른 자음을 고르면 새 코스를 시작한다. 선택한 도트 고양이가 달리기·점프·숙이기 동작을 표시한다.

### 공통 도트 그래픽과 로컬 실행

세 게임에 같은 도트 팔레트·계단형 구름·타일 지형을 적용한다. 달리기는 선택한 치즈·모찌 고양이를 표시한다. 발성 비행에는 도트 새와 사각 통과 장식을, 단어 게임에는 치즈와 도트 배경을 적용한다. 설명·훈련 단어는 읽기 쉬운 일반 글꼴을 유지한다.

사용자 요청에 따라 기본 로컬 검증은 **macOS 빌드·실행**이다. iPad 빌드·설치는 사용자가 명시적으로 요청할 때만 진행한다.

키보드는 ↑·스페이스로 점프, ↓로 숙이기다. 시작할 때 게임에 키보드 포커스를 지정하며 키를 길게 눌러도 중복 동작하지 않는다. macOS의 음성 시작은 macOS 지원 음성 인식 플러그인에서 마이크·음성 인식 권한을 요청한다. 시작 오류는 하단 조작 버튼 옆에 표시한다.

## 단어 게임의 계속 듣기와 치즈 응원

기본으로 **계속 듣고 자동 판정**이 켜져 있다. 연습 시작/이어가기를 한 번 누르면 녹음과 한국어 음성 인식을 시작한다. 인식된 글이 2.5초 동안 바뀌지 않으면 기존 텍스트 비교로 판정하고, 결과를 1.5초 보여 준 뒤 다음 녹음을 시작한다. 단어가 정확히 일치해야 통과하며, 치즈(노란 코숏 수컷)가 작은 점프와 글로 응원한다. 응원 소리는 재생하지 않는다. 다른 단어로 인식되면 천천히 다시 시도하도록 안내한다. 이는 발음의 임상 평가가 아니다.

하단 **듣기 중지 · 잠시 쉬기**는 항상 접근할 수 있다. 현재 녹음을 마치고 자동 재시작을 취소한다. 앱을 벗어나거나 녹음을 재생할 때도 자동 듣기를 멈춘다. 한 녹음이 30초에 도달하거나 인식·판정에 문제가 있으면 쉬는 상태로 전환하며 무음 시도를 무한히 저장하지 않는다. OS 음성 인식과 판정 사이에는 짧은 듣기 공백이 있으므로 ‘듣는 중’ 표시를 보고 말한다.

버튼 방식을 원하면 쉬는 동안 계속 듣기를 끈다. 기존처럼 녹음 시작과 판정을 직접 누를 수 있다. 녹음과 결과는 기존 기록 정책에 따라 보관되며, 낙하 모드는 녹음·판정 중 움직임을 멈춘다.
