## 사용자가 달라지는 점

말이음(SpeechBridge)은 성인 후천성 마비말장애의 반복 자가훈련을 돕는다. 기본 메뉴는 **오늘 → 훈련 → 게임 → 기록 → 설정**이다. 이전 구현과 이번 미커밋 작업을 함께 정리하며, 과거 설계 문서보다 아래 연결된 현재 기능 문서를 우선한다.

| 기능 | 현재 동작 | 자세한 문서 |
|---|---|---|
| 내 문장 연습 | 직접 입력 또는 사진 보관함·카메라·파일 OCR → 문장 확인 → 날짜별 녹음 두 개 → 각각 AI 피드백·듣기·비교 | [내 문장 설계](sentence-repeat-and-mouth-video-plan.md) |
| 많은 문장 입력 | 기존 30문장·500자 제한 제거, 긴 OCR 목록에서도 다음 버튼 접근 가능 | [입력과 OCR](sentence-repeat-and-mouth-video-plan.md) |
| 긴장 낮추기 | 독립 훈련과 상황별 안내, 휴식과 짧게 나누어 말하기 안내 | [긴장 낮추기 설계](sentence-repeat-and-mouth-video-plan.md) |
| 권한과 화면 | 사진·카메라·마이크 권한 안내, 설정 이동, macOS 음성 권한 경로, 파형을 펼쳐도 조작 버튼 접근 유지 | [구현 범위](sentence-repeat-and-mouth-video-plan.md) |
| 게임 메뉴 | 단어 말하기·한 음절 모험 달리기·목소리로 천천히 날기 세 게임 | [게임 안내](game-menu.md) |
| 치즈·모찌 달리기 | 노란 수컷 치즈/흰 암컷 모찌 선택, 자유 점프·숙이기, 12·16·20개 장애물의 3단계, 편안/도전 모드, 도전 시 재시도 2회 | [달리기 규칙](game-menu.md) |
| 단어 계속 듣기 | 시작 한 번 → 인식 글 2.5초 유지 → 자동 비교 → 결과 1.5초 → 다음 듣기. 30초 제한·오류 시 휴식, 고정 중지 버튼, 치즈의 시각적 응원 | [계속 듣기](game-menu.md) |
| 자동 MPT | 준비 한 번 → 1.5초 소음 확인 → 발성 자동 시작·종료 → 녹음 검토. 종료 확인 무음은 제외, 유효 시도 3회 최장값 | [측정 원리·한계](mpt-measurement.md) |
| 훈련 가용성 | 구강·호흡 훈련은 기본 열림, 개별 항목을 서버 정책으로 제어할 구조 | [관리 API와 구현 수준](training-availability-and-server.md) |

## 기록과 서버

- 내 문장은 수정 이력과 날짜별 녹음 쌍을 보관한다. AI는 녹음별 요청이며 업로드 대상·보관 안내를 확인한다. 텍스트 차이를 임상 발음 점수나 진단으로 해석하지 않는다.
- 문장 분석 서버는 작업 생성·조회·처리·삭제, 소유자 확인, 동의·중복 요청·파일 검증과 로컬 Whisper 연동을 제공한다. 모델·서버 설정이 필요하다. 운영 인증 발급, 관리 UI와 다중 프로세스 큐는 별도 과제다. [서버 실행 문서](../server/pronunciation_analysis/README.md).
- 단어 게임 녹음은 기존 기록 정책을 따른다. 달리기는 녹음·스테이지 진행을 영구 저장하지 않는다. MPT는 일반 훈련량과 게임 결과에서 분리한다.
- 자동 MPT는 음향 경계의 추정이며 모음·한 호흡·기침을 자동 검증하지 않는다. 녹음 검토를 통과한 시도만 결과에 포함한다. 구형 수동 MPT 기록도 읽을 수 있다.

## 사용 및 배포 자료

[그림 사용자 가이드](https://clevekim00.github.io/mj_dialog/user-guide.html) · [앱 소개](https://clevekim00.github.io/mj_dialog/promotion.html) · [언어 탭 문서 홈](https://clevekim00.github.io/mj_dialog/documents.html). 한국어가 기본이며 영어 탭에서 대응 문서를 읽는다. GitHub README 자체는 임의의 동적 탭을 지원하지 않으므로 문서 웹사이트에서 탭을 제공한다.

`eli5` 가이드는 큰 그림과 짧은 단계로 기능을 설명한다. 그림은 실제 화면 캡처가 아닌 설명용 삽화다. 사용자 문구와 상세 구현 문서는 국문·영문을 함께 유지한다.

## 검증과 남은 범위

이번 변경의 자동화 테스트에는 자동 듣기 재시작·중지·무음, 늦은 STT 결과 차단, 게임 스테이지·재시도, PCM 신호 기반 MPT 구간, 수동 MPT 호환, OCR 입력·권한·저장 실패가 포함된다. 문서 빌드·번역본·탭·링크 검사와 정적 분석을 수행한다. macOS 디버그 빌드·실행을 기본 확인하며 iPad 빌드·설치는 요청 시에만 한다.

실제 약한 발성·소음에서의 MPT 정확도, 플랫폼별 실기기 권한·오디오 조합, 임상 타당성은 자동 테스트만으로 확인되지 않는다. 앱스토어 심사·서명·운영 서버 배포 완료를 뜻하지 않는다. GitHub main 푸시는 기존 Pages 워크플로를 실행해 문서 사이트를 배포한다.

푸시 전 검증: Flutter 전체 테스트 **212개 통과**, 문장 분석 서버 테스트 **37개 통과**. 최근 macOS 디버그 빌드·실행과 자동 MPT 화면 진입을 확인했다.
