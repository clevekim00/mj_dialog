# Voice Tools 기능 분석 및 Speech Rehab 통합 계획

작성일: 2026-08-24  
분석 대상: [Voice Tools — App Store](https://apps.apple.com/us/app/voice-tools/id1447495900)  
개발사: DevExtras Ltd

## 1. 결론

Voice Tools의 음성 분석 기능은 현재 Speech Rehab의 마비말장애 자가훈련 방향과 잘 맞는다. 다만 원본 앱의 주 사용 목적에는 성별 연관 음역 표시와 트랜스젠더 음성훈련이 포함되어 있으므로, 이를 그대로 복제하기보다 마비말장애 재활 목표에 맞게 다음과 같이 바꾸는 것이 적절하다.

- 피치 분석 → `목소리 높이·안정성 훈련`
- 음량 분석 → `편안하고 일정한 목소리 크기 훈련`
- 목표 톤 재생 → `목표음 따라 내기`
- 스펙트로그램 → `발성 파형·음색 관찰`
- 균형 문장 → `한국어 발음 균형 문장 읽기`
- 최근 10초 녹음 → `즉시 듣고 비교하기`
- 종합 통계 → `발성 분석 결과`
- 성별 연관 피치 비율 → 도입하지 않고 `사용자 개인 기준 범위`로 대체

사용자가 요청한 “발음 음파 분석”은 우선 `발성 훈련`에 배치하는 판단이 맞다. 피치, 음량, 지속시간과 스펙트럼은 발성의 높이·강도·안정성·음질을 보여주는 지표다. 이것만으로 특정 자음이나 모음의 발음 정확도를 판정할 수는 없다. 발음 메뉴에서는 목표 음성과 사용자 음성의 시간 정렬, 음소 인식, 포먼트 또는 음향 특징 비교가 추가된 경우에만 보조 지표로 사용해야 한다.

## 4. 개별 메뉴 구성안

Voice Tools의 치료 관련 기능은 모두 개별 메뉴로 제공한다. 공통 분석 엔진을 사용하되 사용자가 목적을 이해하기 쉽도록 메뉴를 나눈다.

### 4.1 실시간 목소리 높이

- 경로: `/voice_pitch`
- 표시: 현재 Hz, 개인 목표 범위, 실시간 선 그래프, 안정 구간 비율
- 기본 과제: 편안한 `아` 3초, 5초, 짧은 문장
- 저장 지표: 유효 F0 비율, 중앙 F0, F0 범위, 변동성
- 금지 표현: 남성/여성 목소리 판정, 정상/비정상 피치
- 현재 앱 연결: `발성 훈련 > 목소리 높이`

### 4.2 목표음 따라 내기

- 경로: `/target_tone`
- 표시: 기준 톤 재생, 목표 Hz/음표, 사용자 현재 피치, 오차 범위
- 진행: 기준음 듣기 → 편안하게 모음 발성 → 결과 확인
- 초기 범위: 사용자가 무리하지 않는 개인 기준 범위 안에서만 목표 생성
- 현재 앱 연결: `발성 훈련 > 목표음 따라 내기`

### 4.3 목소리 크기

- 경로: `/voice_volume`
- 표시: 상대 음량 그래프, 현재 범위, 문장 끝 음량 변화
- 과제: 모음 지속, 숫자 세기, 짧은 문장
- 저장 지표: 보정된 상대 dBFS, 중앙값, 변동폭, 목표 구간 유지율
- 주의: 스마트폰만으로 실제 SPL dB를 정확히 측정했다고 표시하지 않는다. 기기별 보정 전에는 `상대 음량`이라고 명시한다.
- 현재 앱 연결: `발성 훈련 > 목소리 크기`

### 4.4 발성 음파 분석

- 경로: `/voice_spectrogram`
- 표시: 파형, 스펙트로그램, 피치 궤적, 음량 궤적, 녹음 위치
- 과제: `아` 지속, 부드러운 발성 시작, 높낮이 이동, 짧은 문장
- 초급 화면: 파형+피치+음량만 제공
- 고급 화면: 스펙트로그램, 배음 구조와 무성 구간 표시
- 현재 앱 연결: `발성 훈련 > 발성 음파 분석`

### 4.5 한국어 발음 균형 문장

- 경로: `/balanced_sentences`
- 표시: 문장, 주요 말소리, 읽기 녹음, STT 결과, 즉시 재생
- 콘텐츠: 한국어 초성·중성·종성과 주요 조음 위치가 고르게 포함되도록 임상 검토
- 난이도: 짧은 문장 → 긴 문장 → 기능적 생활 문장
- 현재 앱 연결: 기존 `PracticeContentService`와 `PracticeScreen` 재사용

### 4.6 10초 즉시 녹음

- 경로: `/quick_voice_recording`
- 동작: 최대 10초 순환 버퍼 또는 명시적 10초 녹음, 즉시 재생, 다시 녹음
- 기본 정책: 저장하지 않음
- 선택 기능: `기록에 저장`, `기준 음성으로 저장`, `삭제`
- 현재 앱 연결: 기존 `AudioRecorderService`와 `AudioPlayerService` 확장

### 4.7 발성 분석 결과

- 경로: `/voice_analysis_result`
- 표시: 중앙 피치, 편안한 피치 범위, 상대 음량, 지속시간, 유성 비율, 피치·음량 안정성, 배경 소음 품질
- 비교: 같은 과제의 직전 기록과 비교
- 해석: “향상/퇴보” 대신 “이번 측정에서 더 일정했어요” 같은 관찰형 표현
- 현재 앱 연결: 통합 `RehabSession`과 달력 상세

### 4.8 나의 기준 음성

- 경로: `/voice_bank`
- 기능: 사용자가 선택한 녹음을 기준 음성으로 보관, 제목·과제·날짜 지정, 현재 녹음과 번갈아 듣기
- 제한: 자동 업로드 없음, 로컬 저장, 개별 삭제와 전체 삭제 제공
- 현재 앱 연결: `RecordingLibraryScreen`을 유형 필터가 있는 통합 음성 보관함으로 확장

### 4.9 발성 분석 기록

- 경로: `/voice_analysis_history`
- 기능: 날짜·과제·메뉴별 분석 기록, 추세 그래프, 달력 연결
- 저장: 원시 오디오는 선택 사항, 요약 지표만 저장 가능
- 현재 앱 연결: 새 통합 달력의 날짜 상세에서 진입

### 4.10 마이크·소음 점검

- 경로: `/microphone_check`
- 기능: 권한, 입력 신호, clipping, 배경 소음, 샘플레이트, 마이크 거리 안내
- 결과: `분석 가능`, `조용한 곳에서 다시 시도`, `마이크에 너무 가까움`
- 현재 앱 연결: 모든 실시간 분석 메뉴의 공통 시작 단계

## 5. “발음 음파 분석” 배치 검토

### 권장 판단

주 메뉴명은 `발성 음파 분석`으로 하고 `발성 훈련` 아래 배치한다.

이유:

1. 파형은 시간과 진폭, 스펙트로그램은 시간과 주파수 에너지를 보여준다.
2. 피치와 음량은 성대 진동, 호흡-발성 협응, 운율과 더 직접적으로 연결된다.
3. 자음·모음 발음 정확도는 목표 음소, 조음 위치, 문맥과 시간 정렬을 함께 봐야 한다.
4. 스펙트로그램 모양이 다르다는 이유만으로 발음 오류나 치료 효과를 판정하면 오해가 생긴다.

### 발성 훈련에서 제공할 분석

- 지속 발성 시간
- 중앙 기본주파수 F0
- F0 범위와 변동성
- 유효한 유성 프레임 비율
- 상대 음량 중앙값과 변화폭
- 문장 끝 음량 감소
- 발성 시작까지 걸린 시간
- 배경 소음과 분석 신뢰도

### 발음 훈련에서 제한적으로 재사용할 분석

- 목표음과 사용자 음성의 파형 재생 위치 맞추기
- 음절 길이와 쉼 비교
- 모음 구간의 포먼트 참고값
- 무성/유성 구간과 음성 시작 시간 참고
- 음소 단위 STT 또는 별도 forced alignment가 있을 때의 구간 비교

발음 화면에서는 스펙트로그램을 `정답 그래프`로 사용하지 않고 `듣기와 함께 보는 참고 화면`으로 제공한다.

## 6. 현재 Speech Rehab과의 기능 차이

| 영역 | 현재 상태 | 필요한 추가 작업 |
|---|---|---|
| 녹음 | `record`와 iOS MethodChannel로 M4A 파일 저장 | 실시간 PCM 스트림과 10초 메모리 버퍼 추가 |
| 재생 | 녹음 파일 재생 지원 | 순환 버퍼 즉시 재생, A/B 기준 음성 비교 |
| STT | 문장 인식과 발음 연습에 사용 | 음향 분석과 독립적으로 유지 |
| 피치 | 구현 없음 | F0 추정 엔진과 voiced/unvoiced 판정 추가 |
| 음량 | 구현 없음 | RMS, peak, dBFS, clipping과 noise floor 계산 |
| 스펙트로그램 | 구현 없음 | windowing, FFT, magnitude/dB 변환과 렌더링 추가 |
| 목표 톤 | 구현 없음 | 사인파/안전한 기준음 생성 및 재생 추가 |
| 결과 저장 | `PracticeSession`이 텍스트·점수 중심 | `VoiceAnalysisMetrics`와 원시 프레임 요약 추가 |
| 달력 | 별도 설계 단계 | 통합 `RehabSession`에 분석 메뉴 기록 연결 |
| 호흡·발성 | 현재 호흡 화면에 얼굴·입술·혀 동작이 혼합 | 호흡 메뉴와 발성 분석 메뉴를 분리 |

### 7.2 데이터 흐름

```text
마이크 PCM 입력
  -> DC 제거/정규화
  -> 20~40ms 프레임 분할
  -> 배경 소음 및 clipping 검사
  -> 병렬 분석
      -> F0 추정 + confidence
      -> RMS/peak/dBFS
      -> FFT/spectrogram bin
  -> 화면용 저주기 샘플링
  -> 10초 ring buffer
  -> 세션 종료 통계
  -> 선택적 로컬 저장
  -> RehabSession/달력 연결
```

### 7.3 핵심 데이터 모델

```dart
class VoiceAnalysisMetrics {
  final double? medianPitchHz;
  final double? meanPitchHz;
  final double? minPitchHz;
  final double? maxPitchHz;
  final double pitchVariability;
  final double voicedFrameRatio;
  final double medianDbfs;
  final double volumeVariability;
  final double noiseFloorDbfs;
  final double clippingRatio;
  final int phonationDurationMs;
  final double analysisConfidence;

```

`VoiceAnalysisSession`에는 `taskType`, `promptId`, `startedAt`, `duration`, `metrics`, `audioPath?`, `routineSessionId?`, `analysisVersion`, `deviceCalibrationId?`를 저장한다.

### 7.4 분석 원칙

- 피치 대표값은 이상치에 덜 민감한 중앙값을 기본으로 한다.
- confidence가 낮거나 무성음으로 판단된 프레임은 F0 통계에서 제외한다.
- 음량은 보정 전 `dB SPL`이 아니라 `dBFS/상대 음량`으로 표시한다.
- 화면 렌더링 주기와 오디오 분석 주기를 분리해 UI 부하를 줄인다.
- 원본 PCM은 사용자가 저장하지 않으면 10초 ring buffer에서 자동 폐기한다.
- 플랫폼별 동일한 샘플레이트와 프레임 설정을 사용하고 기기 차이를 테스트한다.

```text

      -> 입술 운동
      -> 혀 운동
      -> 호흡 훈련
      -> 발음 훈련
      -> 발성 훈련
          -> 실시간 목소리 높이
          -> 목표음 따라 내기
          -> 목소리 크기
```

사용자는 모든 기능을 개별 메뉴로 실행할 수 있고, 15분 통합 루틴에서는 이 중 일부를 단계로 조합한다. 개별 실행도 `RehabSession`에 저장하되 일일 15분 루틴 완료와는 별도 상태로 표시한다.

## 9. 15분 루틴에 넣는 방법

Voice Tools 계열 기능을 한 세션에 모두 사용하면 화면 복잡도와 피로가 커진다. 표준 루틴에서는 아래처럼 일부만 사용하고, 전체 기능은 개별 메뉴에서 제공한다.

| 루틴 구간 | 연동 기능 | 시간 |
|---|---|---:|
| 안전·마이크 점검 | 마이크·소음 점검 | 30초 |
| 호흡-발성 | 음량 그래프 또는 지속 모음 | 2분 30초 |
| 입술·혀-말소리 | 기존 운동과 음절 발화 | 3분 |
| 발음 | 균형 단어·문장, 10초 녹음 | 4분 |
| 발성·운율 | 피치/음량 중 하루 한 지표, 기능 문장 | 4분 |
| 마무리 | 즉시 재생과 짧은 결과 | 1분 |

피치, 음량, 스펙트로그램은 매 세션 모두 보여주지 않고 사용자의 주 목표에 따라 하나를 전면에 둔다. 시각 정보가 많으면 마비말장애 사용자의 인지 부담과 수행 간섭이 커질 수 있기 때문이다.

## 10. 개발 단계

### Phase 1 — 공통 오디오 분석 기반

- 실시간 PCM 입력
- 10초 ring buffer
- RMS/peak/dBFS 및 clipping
- F0와 confidence
- 마이크·소음 점검
- 분석 결과 데이터 모델

완료 조건: 저장 없이 10분 연속 분석해도 누수·끊김이 없고, 무음·소음·음악을 음성 피치로 잘못 표시하는 비율이 허용 범위 안에 있어야 한다.

### Phase 2 — 독립 메뉴 MVP

- 실시간 목소리 높이
- 목표음 따라 내기
- 목소리 크기
- 10초 즉시 녹음
- 발성 분석 결과

완료 조건: 각 기능이 별도 라우트로 열리고 분석 실패 시 이유와 재시도 방법을 표시한다.

### Phase 3 — 스펙트로그램과 콘텐츠

- 발성 음파 분석
- 한국어 발음 균형 문장
- 파형과 녹음 위치 동기화
- 초급/고급 시각화 전환

완료 조건: 스펙트로그램이 진단 또는 발음 정답처럼 보이지 않으며 언어재활사 검토를 통과한다.

### Phase 4 — 이력과 통합 루틴

- 나의 기준 음성
- 발성 분석 기록
- 통합 `RehabSession`
- 훈련 달력 연결
- 15분 루틴의 발성 단계 편입

완료 조건: 같은 날짜의 여러 개별 메뉴와 통합 루틴 기록이 구분되고, 녹음 삭제 후 통계와 달력이 일관되게 유지된다.

## 11. 검증 계획

### 신호처리 검증

- 100, 150, 200, 250Hz 합성 신호의 피치 오차
- 남녀 구분이 아닌 다양한 성인 음역과 거친·기식성 음성 샘플
- 무음, 백색소음, TV 소리, 음악에서의 오검출
- 작은 음량, clipping, 마이크 거리 변화
- iOS/Android 기기별 샘플레이트와 지연

### 임상·사용성 검증

- 피치·음량을 정상/비정상 또는 치료 성공으로 오해하지 않는지
- 큰 그래프를 보면서도 과도하게 힘주어 말하지 않는지
- 편측 운동장애 사용자가 한 손으로 조작 가능한지
- 한 화면 한 목표와 큰 중단 버튼이 유지되는지
- 피로도 4~5일 때 경량 또는 종료 선택이 명확한지

### 개인정보 검증

- 기본값은 저장 안 함
- 화면 이탈 시 ring buffer 폐기
- 음성 저장 전 명시적 확인
- 개별 녹음·기준 음성·전체 기록 삭제
- 클라우드나 AI 전송이 생길 경우 별도 동의와 전송 표시

## 14. 최종 권고

기능을 독립 메뉴로 모두 제공하되 구현은 화면별로 따로 만들지 말고 하나의 실시간 음성 분석 엔진을 공유해야 한다. 첫 개발 범위는 `마이크 점검 → 피치 → 상대 음량 → 10초 재생 → 결과`로 잡고, 스펙트로그램과 한국어 균형 문장은 두 번째 단계에서 추가하는 것이 안전하다.

발성 음파 분석은 사용자의 제안대로 발성 훈련에 배치한다. 발음 훈련에서는 기존 STT·목표 문장·녹음 비교를 중심으로 유지하고, 음파는 사용자가 듣는 위치를 찾거나 모음·길이·쉼을 관찰하는 보조 화면으로만 연결한다.
