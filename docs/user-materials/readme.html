게임 메뉴

기본 메뉴는 오늘 → 훈련 → 게임 → 기록 → 설정입니다. 게임에서 단어 말하기 게임(시간 제한 없음이 기본)과 목소리로 천천히 날기를 선택합니다. 구강 훈련과 MPT는 훈련에 남습니다. 기록의 게임 필터에서 두 게임 기록을 확인합니다. 현재 메뉴와 기존 기록 호환성.

최대발성시간 (MPT)

훈련 → 편안하게 소리 내기 → 최대발성시간 (MPT)에서 보호자·검사자가 한 호흡의 “아~” 발성을 3회 측정합니다. 확인된 세 시도 중 최장 시간을 녹음·파형과 함께 별도 MPT 기록으로 저장합니다. 시도 사이에는 충분히 쉬며, 중단·미확인 시도는 결과에서 제외합니다. 시행 절차를 기록하는 기능으로, 임상 검증을 마친 진단 도구는 아닙니다.

📌 프로젝트 개요

말이음(SpeechBridge)은 성인 후천성 마비말장애 사용자가 집에서도 짧고 꾸준하게 말하기 연습을 할 수 있도록 돕는 앱입니다. 음성 기반 대화, 소리 내어 읽기, 녹음 재생, 피로도/목표 기록, 연습 히스토리를 통해 사용자와 보호자가 변화 과정을 확인할 수 있게 설계합니다.

이 앱은 전문적인 평가나 도움을 대체하지 않는 연습 보조 도구입니다. 필요할 때는 전문가와 상의해 연습 계획을 조정하는 것을 권장합니다.

  • 🏁 오늘의 연습 우선 진입 — 앱 실행 시 오늘 할 연습을 바로 고를 수 있는 홈 화면으로 시작

  • 🧑‍⚕️ 연습 세션 기록 — 오늘 목표, 시작 전 피로도, 녹음 시간, 피드백을 함께 저장

  • 🤖 확인 가능한 피드백 — 읽기 연습의 텍스트 일치도를 표시하고, 인식 실패·자유 말하기에는 점수를 만들지 않음
  • 🕗 통합 히스토리 관리 — AI 대화와 읽기 연습 기록을 한데 모아보고 필터링할 수 있는 일원화된 저장소

📋 최근 개선 사항 (Changelog)

2026-09-15 · 자음 선택과 연습 안정성

  • 홈의 자음 골라 연습하기에서 초성·받침을 선택하고 음절·단어·문장을 3·5·10회 녹음합니다. 목표 음절 강조, 동일 항목 녹음 비교, 완료·이어하기를 제공합니다.
  • 자음·문장 화면에서 녹음/중지 버튼을 하단에 고정하고, 진행 중 항목 변경과 녹음 이탈을 보호합니다.
  • 구강·호흡 훈련은 선택한 반복 수를 유지하고 자동 저장·부분완료·이어하기를 제공합니다. 온보딩 목표와 일일 시간을 홈에 반영합니다.
  • 단어 연습의 기본은 시간 제한 없음입니다. 과거 방식 점수와 미평가 기록은 새로운 텍스트 일치도 통계에서 분리합니다.
  • 서버 분석은 별도 동의 후 요청하며, 취소·전체 제한시간·접근권한·결과 만료를 적용합니다. 운영 인증 서버 연동과 임상 검증은 별도로 필요합니다.

상세 사용 흐름·검증·남은 범위는 구현 기록에 있습니다. 아래 항목은 이전 변경 시점의 기록입니다.

0. 구조화된 발음 연습 모드

  • 한컴타자연습처럼 단어 게임, 짧은 문장 읽기, 긴 문장 읽기, 자유 대화를 선택하는 연습 선택 화면을 추가했습니다.
  • 단어 게임은 떨어지는 단어를 발음해서 맞히면 사라지고, 단어가 바닥에 닿으면 종료되는 게임형 UI로 동작합니다.
  • 단어 게임을 전용 화면으로 분리해 게임 보드, 난이도, 점수, 말하기 컨트롤만 집중해서 보여줍니다.
  • 단어 게임에서 70점 미만으로 실패한 단어를 틀린 단어 복습으로 다시 연습할 수 있습니다.
  • 단어 게임은 쉬움/보통/집중 난이도에 따라 일반 단어와 혀 움직임이 많은 운동 음절의 출현 빈도를 조절합니다.
  • 단어/문장을 PracticeContentItem으로 구조화해 모드, 카테고리, 난이도, 목표 발음을 함께 관리합니다.
  • 긴 문장 모드에서 사용자가 반복 연습할 내 긴 문장을 추가, 수정, 삭제할 수 있습니다.
  • 연습 기록에 모드, 콘텐츠 ID, 카테고리, 난이도, 재시도 횟수, 연속 성공 정보를 저장합니다.
  • 대시보드와 기록 화면에서 모드별 연습 내역과 어려웠던 발음군을 확인할 수 있습니다.

0. 혀운동 루틴 및 2D 튜터 가이드

  • 오늘의 연습 홈의 운동 카드에서 혀운동, 얼굴운동, 호흡훈련을 선택할 수 있습니다.
  • 혀운동 메뉴 아래에는 기존 혀운동 루틴과 연속 교대운동 메뉴가 있습니다.
  • 오늘의 연습 홈에 연습 전 준비운동 / 혀운동 3분 카드를 배치해 발화 연습 전 워밍업으로 진입할 수 있게 했습니다.
  • 얼굴운동, 호흡훈련, 연속 교대운동 화면에는 임시 교육용 애니메이션 아바타를 다시 표시합니다.
  • 추후 Rive/Lottie/Live2D 에셋이 준비되면 같은 운동 단계와 2D mouth-shape 이름을 기반으로 교체할 수 있습니다.
  • 대시보드의 혀운동 루틴 카드에서 최근 7일 완료 일수와 평균 소요 시간을 확인하고, 오늘 완료 후에도 다시 실행할 수 있습니다.
  • 혀운동 화면에 시작 전/후 피로도, 안전 안내, 단계별 타이머, 일시정지/다음/중단, 완료 기록 저장 흐름을 추가했습니다.
  • 완료 화면에 혀운동 다시 하기 버튼을 추가해 같은 세션에서 루틴을 여러 번 반복할 수 있습니다.
  • 혀운동 준비 화면과 진행 화면의 3D GLB 미리보기는 제거하고, 첨부 레퍼런스 방향의 2D 튜터 가이드로 교체했습니다.
  • 혀 모양은 3D 모델이 아니라 Canvas 기반 2D 레이어로 처리합니다. 입술 외곽, 입 안쪽, 치아, 혀, 혀 중앙선, 볼 밀기 하이라이트를 단계별 animationType에 맞춰 그립니다.
  • model_viewer_plus 의존성과 assets/models/tongue_exercise_preview.glb asset 선언을 제거했습니다.
  • 2D 튜터/발음 mouth-shape/운동 라이브러리 장기 설계는 docs/ai-speech-therapy-avatar-platform.md에 정리했습니다.

0. 문장 반복 및 녹음 비교

  • 문장 연습 결과 화면에서 방금 녹음 듣기를 제공하고, 같은 문장을 다시 녹음한 경우 이전 녹음 듣기도 함께 표시합니다.
  • 같은 문장 반복으로 현재 문장을 유지한 채 재녹음할 수 있어, 1-2문장 단위 반복 훈련 흐름을 지원합니다.
  • 녹음 보관함의 다시 연습 버튼으로 과거 문장/단어를 바로 반복 연습할 수 있습니다.
  • 녹음 보관함에서 점수 낮은 순 정렬과 반복 저장 필터를 제공해 어려운 단어/문장을 따로 모아 다시 연습할 수 있습니다.
  • 녹음 보관함의 재생불가 삭제 버튼으로 실제 파일이 사라져 재생할 수 없는 녹음을 한 번에 정리할 수 있습니다.
  • 오늘의 연습 홈에 낮은 점수/재시도 기록 기반 어려웠던 문장 다시 읽기 카드를 표시합니다.
  • 연습 화면의 입모양 촬영 토글을 켜면 녹음과 함께 전면 카메라 무음 영상을 저장하고, 결과 화면에서 입모양 영상 보기로 확인할 수 있습니다.
  • 연습 화면에는 전면 카메라 프리뷰가 표시되며, 녹음 보관함에서도 저장된 입모양 영상을 다시 열 수 있습니다.
  • 자유대화 화면에서도 입모양 촬영 토글을 켜고 대화 중 입모양 영상을 저장한 뒤 마지막 영상을 확인할 수 있습니다.
  • 상세 구현 순서와 남은 개선 항목은 docs/sentence-repeat-and-mouth-video-plan.md에 정리했습니다.

0. 말하기 어려움 연습 목적 반영

  • 최초 실행 시 안전 고지와 연습 목표 설정을 확인하는 온보딩을 추가했습니다.
  • 연습 세션에 오늘 목표, 시작 전 피로도, 녹음 시간을 함께 저장하도록 확장했습니다.
  • 병원/집/가족/전화 상황에서 바로 쓸 수 있는 기능적 의사소통 문장을 추가했습니다.
  • 대시보드에 최근 7일 연습 지속성과 평균 피로도 정보를 추가했습니다.

1. 소리 내어 읽기 연습 (Reading Practice) 추가

  • 사용자가 제시된 문장이나 직접 입력한 문장을 읽고 발음 점수와 피드백을 받을 수 있는 기능을 추가했습니다.
  • 녹음된 자신의 목소리를 다시 들어보며 AI '영은'의 구체적인 코칭을 확인할 수 있습니다.

2. 자유 읽기 (Free Reading) 및 통합 히스토리

  • 정해진 문장 없이도 자유롭게 말하고 평가받는 '자유 읽기' 모드를 도입했습니다.
  • 메인 히스토리 화면에서 대화 세션과 연습 세션을 통합하여 조회하고 필터링할 수 있는 기능을 완성했습니다.

3. 고도화된 UI 및 버그 수정

  • 스크롤 뷰 도입을 통해 긴 피드백 카드 노출 시 발생하던 Bottom Overflow 문제를 해결했습니다.
  • 발음 연습을 상징하는 전용 아이콘과 프리미엄 뱃지 요소를 적용했습니다.

🚀 실행 방법

사전 요구사항

  • Flutter 3.38+ 설치
  • Gemma 2B 모델 파일 (모바일): assets/gemma-2b-it-gpu-int4.bin

빌드 & 실행

# 의존성 설치
flutter pub get

# macOS 실행
flutter run -d macos

# iOS 실행 (권장)
flutter run -d ios

# iOS 실기기 release 실행 (홈 화면 단독 실행 확인용)
scripts/run_ios_release_device.sh

# Android 실행
flutter run -d android

iOS 실기기 release 실행 스크립트

다음 긴 명령은 iOS debug 앱의 홈 화면 단독 실행 제한을 피하고, 실제 기기에서 release 빌드를 바로 설치/실행하기 위한 명령입니다.

flutter run --release -d 00008027-000849220A31002E --no-resident

항상 같은 방식으로 실행할 수 있도록 아래 스크립트로 고정했습니다.

scripts/run_ios_release_device.sh

다른 기기를 지정해야 할 때는 다음처럼 실행합니다.

scripts/run_ios_release_device.sh --device <device-id>

또는 환경 변수로 기본 기기를 바꿀 수 있습니다.

Games

Use Today → Training → Games → Records → Settings. Games contains Word speaking game (untimed by default) and Gentle voice flight. Oral training and MPT stay under Training. In Records, select Games to see both games. Current navigation and compatibility.

Maximum phonation time (MPT)

Training → Comfortable voice practice → Maximum phonation time (MPT) provides observer timing for three single-breath “ah” trials. The longest of three confirmed trials is saved with recordings and waveforms in the separate MPT record category. Rest between trials; interrupted or unreviewed attempts do not count. This is a protocol recording tool, not a clinically validated diagnostic test.

📌 Project overview

Malieum (SpeechBridge) helps adults with acquired dysarthria practice speaking briefly and regularly at home. Voice conversation, reading aloud, recording playback, fatigue/goal records, and practice history are designed to help users and caregivers review changes over time.

This is a practice-support tool, not a substitute for professional assessment or support. Consult a professional when adjusting a practice plan.

Key features

  • 🏁 Today's practice first — Start on Home and choose today's activity directly.
  • 🧭 Practice onboarding — Set safety acknowledgement, practice period, goals, and fatigue criteria on first use.
  • 🎙 Flexible conversation input — Use speech, keyboard, or prepared phrases.
  • 📖 Structured pronunciation practice — Separate word game, short sentences, long sentences, and free speech for repetition.
  • 🧑‍⚕️ Session records — Save today's goal, pre-practice fatigue, recording duration, and feedback.
  • 🛡 Permission guidance — Explain microphone/speech-recognition permissions to first-time users.
  • 🤖 Checkable feedback — Show text match for reading; do not invent scores for recognition failures or free speech.
  • 🕗 Unified history — Review and filter AI conversations and reading practice together.

🚀 Running the app

Prerequisites

  • Flutter 3.38+
  • Gemma 2B model for mobile: assets/gemma-2b-it-gpu-int4.bin

Build and run

# Install dependencies
flutter pub get

# Run on macOS
flutter run -d macos

# Run on iOS (recommended)
flutter run -d ios

# Release build on a physical iOS device; verify standalone Home-screen launch
scripts/run_ios_release_device.sh

# Run on Android
flutter run -d android

Physical iOS release script

The following command avoids the standalone Home-screen launch limitation of iOS debug apps and directly installs/runs a release build on the device:

flutter run --release -d 00008027-000849220A31002E --no-resident

Use the script for a consistent invocation:

scripts/run_ios_release_device.sh

Choose another device:

scripts/run_ios_release_device.sh --device <device-id>

Or override the default through an environment variable:

IOS_DEVICE_ID=<device-id> scripts/run_ios_release_device.sh
