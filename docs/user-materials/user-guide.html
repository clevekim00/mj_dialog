큰 파형이 더 좋은 발음이라는 뜻은 아니에요. 마이크 거리와 주변 소리에도 달라져요.

카메라 허용이 필요해요. 이 거울은 영상을 저장하지 않아요. 꺼 두고 연습해도 돼요.

목소리로 천천히 날기

훈련 → 편안하게 소리 내기
→ 목소리로 천천히 날기

① 피로 상태를 고르고 시작해요.
② 처음에는 잠깐 조용히 기다려요.
③ 편안하게 “아~” 소리를 내 봐요.

소리가 잡히면 새가 움직여요.
높낮이가 달라지면 새의 높이도 조금 달라져요.

힘들면 ‘멈추고 쉬기’를 눌러요.

새가 멈춰도 실패가 아니에요

앱이 소리를 잘 못 읽었을 수 있어요.
